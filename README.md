# ITEC 85 Inventory System

## Instructions

1. Clone niyo lang tong repo sa github (copy niyo to)
    - git clone https://github.com/kyleandreibaltazar/itec-85-inventory-system.git
2. Sa vscode extension, idownload niyo yun SQLite & SQLite Viewer para ma view niyo si /database/inventory.sqlite
3. Para maopen niyo, sa terminal:
    - php -S 127.0.0.1:8080
4. Then punta kayo sa browser and open 127.0.0.1:8080
